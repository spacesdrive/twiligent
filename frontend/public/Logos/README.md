# Logos

All vector files are outlined (no fonts needed). Pick by background, not by taste.

- `twiligent-lockup-horizontal.svg`: primary logo: colour mark + wordmark in Dusk (#140E10). Paper and white grounds.
- `twiligent-lockup-horizontal-reversed.svg`: colour mark + white wordmark. Dusk and other dark grounds.
- `twiligent-lockup-horizontal-dusk.svg`: single ink, Dusk (#140E10). One-colour print, embossing, faxes, legal.
- `twiligent-lockup-horizontal-white.svg`: single ink, white. On Twiligent Red, the fold gradient and photography.
- `twiligent-lockup-stacked.svg` / `-stacked-reversed.svg`: stacked version for square spaces: avatars, splash screens, merch.
- `twiligent-mark-color.svg`: the mark alone, vector redraw of the original with the fold gradients.
- `twiligent-mark-red.svg` (ink #C11F2F), `twiligent-mark-dusk.svg` (ink #140E10), `twiligent-mark-white.svg` (ink #FFFFFF): single-colour marks with small gaps where one ribbon passes under another. Use below 24px and on any coloured ground.
- `twiligent-wordmark-dusk.svg`, `twiligent-wordmark-white.svg`: the name alone, Sora SemiBold, −2% tracking.
- `twiligent-mark-original.png`: the supplied artwork (1921×1663, transparent). The master for the shading; use for large raster work.
