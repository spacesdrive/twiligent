# App icons

Rounded-square icons with the mark at 62% width. Each comes as SVG plus 512, 180 (Apple touch) and 32px PNG.

- `twiligent-app-icon-dusk`: the default: colour mark on Dusk (#140E10).
- `twiligent-app-icon-red`: white single-colour mark on Twiligent Red (#C11F2F).
- `twiligent-app-icon-paper`: colour mark on Paper (#F7F3EF).
- `twiligent-favicon.svg` / `-32.png`: red single-colour mark on Dusk, tuned for tab size.
