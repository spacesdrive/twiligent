export const meta = { title: 'YouTube API key', description: 'One shared key lets every member add any public channel.' }

<Steps>
<Step title="Create a Google Cloud project">

Open [Google Cloud Console](https://console.cloud.google.com/projectcreate) and create a project, for example `twiligent`.

</Step>
<Step title="Enable the YouTube Data API">

Open [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) in the API Library, make sure your new project is selected, and choose **Enable**.

</Step>
<Step title="Create the key">

Open **APIs and Services**, then [Credentials](https://console.cloud.google.com/apis/credentials). Choose **Create credentials**, then **API key**. Copy the key; it starts with `AIza`. This is `YOUTUBE_API_KEY`.

</Step>
<Step title="Restrict the key">

Edit the key. Under **API restrictions** choose **Restrict key** and select only YouTube Data API v3. Leave **Application restrictions** at None, because the key is used by the Worker, not a browser.

</Step>
</Steps>

<Callout type="tip" title="Quota">

The free quota is 10,000 units a day, shared by all members. Most reads cost 1 unit. Adding [Upstash Redis](/docs/self-host/redis) caches results and makes the quota go much further.

</Callout>
