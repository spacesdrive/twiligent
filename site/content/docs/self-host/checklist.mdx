| Check | How |
| --- | --- |
| Backend is up | `/api/health` on your backend URL returns status ok. |
| Backend is ready | `/api/health/ready` returns status ready. If it names a missing secret, set it and deploy again. |
| Sign-in works | On the site, sign in with an emailed code (or Use password, then Create one with a password), and with Continue with Google if you set it up. |
| Keys are detected | Settings, Server API keys shows YouTube, Instagram and Cloudinary as set. |
| YouTube works | Add any public channel in Accounts. |
| Instagram works | Connect your own tester account in Accounts. |
| Publishing works | Schedule a post 5 minutes ahead. It shows Published within 20 minutes. |
| Data is private | `npm run db:status` shows every migration applied, and the Table Editor shows no "RLS disabled" warning on the four tables. |
| Signups match your plan | Turn off new signups in Supabase if the instance is private. |
| Members can reach you | VITE_ADMIN_EMAIL is your address. |

## Tell your members

Send them the site address and a link to [Using Twiligent](/docs/use/getting-started). They need nothing else. If they will connect Instagram, collect their usernames and add them as testers first.
