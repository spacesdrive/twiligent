## Add an item

Open **Tracked content** and choose **Track content**. Paste a YouTube video or Shorts link. Add an optional label and category, then choose **Track**.

## Categories

Categories group items, for example by campaign. Each category gets its own page in the sidebar with combined views, likes and comments. To set a category on many items, select them with the checkboxes and use **Assign category**.

## Where the numbers come from

Views, likes and comments are fetched from YouTube, so there is nothing to type in by hand.

## Keep numbers current

Use the refresh button on a row to fetch the latest views, likes and comments for that item.
