## Add an item

Open **Tracked content** and choose **Track content**. Paste a Reddit post link or a YouTube video or Shorts link. Add an optional label and category, then choose **Track**.

## Categories

Categories group items, for example by campaign. Each category gets its own page in the sidebar with combined views, karma and comments. To set a category on many items, select them with the checkboxes and use **Assign category**.

## Views and images for Reddit posts

Reddit does not report views, so use **Edit** to enter the number from the post's insights page. Reddit posts also have no thumbnail; you can upload a screenshot so you recognise the post at a glance.

## Keep numbers current

Use the refresh button on a row to fetch the latest karma, likes and comments for that item.
